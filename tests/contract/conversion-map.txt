# Where a Python contract test's Rust twin is, when not where the default name puts it, or
# why it has none. Read by check_conversion.py, whose docstring gives the default name
# (contract_<file>.<Class>.<test_name> -> <file>::<snake_case(Class)>::<test_name>).
#
# One entry per line; blank lines and lines starting with # are ignored:
#
#   <python id> -> <rust id>                      a twin under another name
#   <python id> -> <rust id>  # <note>            the same, with a note for the reviewer
#   <python id> -> retired: <reason>              a Python-specific check with nothing to convert
#   <python id> -> retired: <reason>  # <note>
#
# <python id> is the unittest id, contract_<file>.<Class>.<test_name>; <rust id> is
# <file>::<path in tests/<file>.rs>. A note starts at the first " # " after the target and
# runs to the end of the line; check_conversion.py prints every note and every retired
# reason. A retired entry needs a reason, and no two Python tests may name the same Rust test.
#
# A twin, named here or by default, must hold at least as many assertions as its Python test
# (at least one when the Python test counts none), must not be #[ignore] or #[should_panic],
# and must not skip under Python through rust_only() unless its Python test is @rust_only
# (rulings S3-R6, S3-R21; check_conversion.py's docstring gives the counting rules).
